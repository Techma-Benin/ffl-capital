# FFL Capital — UI mock-up

Pencil design file for the Partner and Admin portals (reference for frontend implementation).

## Source file

Open `ffl-capital-ui-mockup.pen` in [Pencil](https://pencil.dev) to view and edit all screens.

## Screens included

1. Partner — Dashboard
2. Partner — Aged leads marketplace (new vs Boberdoo)
3. Partner — Wallet
4. Partner — My leads
5. Partner — Onboarding (min. 15 states)
6. Admin — Operations dashboard
7. Admin — Partners (approval queue)
8. Admin — Refunds (Type A / Type B)
9. Screen inventory map
